    andesim now treats rv32 as a first-class peer of rv64, driven by the ELF's
    class byte (e_ident[EI_CLASS]). See docs/rv32_ROADMAP.md.

    - elf_xlen() reads an ELF's width (32/64). fast auto-picks
      qemu-system-riscv32/64 from the ELF (explicit --engine wins + warns on a
      conflict); cycle and hybrid reject an ELF whose class != the engine's xlen
      via one shared elf_engine_arch_error -- a clear up-front message instead of
      the engine's cryptic "not of ELFCLASSxx".
    
    Dual-arch runtime (runtime/, config, scripts):
    - runtime/Makefile parameterized by ARCH: rv64 -> build/runtime,
      rv32 -> build/runtime/rv32 (rv32gc/ilp32d, riscv32-unknown-elf-).
    - Real rv64-isms fixed: vplat_syscalls.c L2-cache flush guarded to rv64
      (#if __riscv_xlen==64); handler.c trap CSRs made XLEN-wide, which also fixes
      latent rv64 mepc/mtval truncation and the interrupt-bit test.
    - HYBRID_TOOLCHAIN32 config var (a second, separate toolchain);
      build_runtime.sh builds both arches (and its stale artifact names fixed);
      build_all.sh runtime delegates to it.
    
    rv32 fixtures (tests/fixtures/):
    - make rv32 -> rv32_spin (asm) + rv32_c_hello (C, links the rv32 runtime),
      reusing existing sources.
    
    Docs: USER_GUIDE sec 1.3 (two toolchains) + new sec 5.1 (rv32 link command and

+
+The runtime builds for **both** widths from two toolchains (`HYBRID_TOOLCHAIN`

+runtime` builds both when `HYBRID_TOOLCHAIN32` is set:
+

+- rv32 -> `build/runtime/rv32/` (link `-B build/runtime/rv32`).
+
+The rv32 link is the same shape with the rv32 compiler and `-march=rv32gc
+-mabi=ilp32d`:
+
+```sh
+"$HYBRID_TOOLCHAIN32/bin/riscv32-unknown-elf-gcc" -march=rv32gc -mabi=ilp32d -O1 \
+  -B build/runtime/rv32 -specs=andesim.specs your_prog.c -o your_prog.elf
+```
+
+**The driver follows the ELF's width.** `run` reads the ELF's class
+(rv32/rv64) and:
+
+- **fast** auto-selects `qemu-system-riscv32` or `qemu-system-riscv64` to match
+  the ELF -- no flag needed (an explicit `--engine qemu32`/`qemu64` overrides,
+  with a warning if it disagrees with the ELF).
+- **cycle** / **hybrid** reject an ELF whose width does not match the chosen
+  engine, up front, instead of a cryptic failure deep inside the engine:
+
+  ```
+  $ ./andesim run --mode cycle --engine vsim:ax45mpv_premium prog_rv32.elf
+  andesim run --mode cycle: ELF is rv32 but engine 'vsim:ax45mpv_premium' is rv64
+    -- pick a matching engine or an rv64 ELF
+  ```
+

+# ROADMAP: rv32 support (rv32 alongside rv64, end to end)
+
+**Goal.** andesim runs rv32 ELFs as a first-class peer of rv64: `fast` picks the
+matching `qemu-system-riscv32`/`riscv64` from the ELF, `cycle`/`hybrid` reject an
+engine whose width differs, and the runtime + fixtures build for both arches from
+two toolchains.
+
+## Shared facts (one source of truth)
+
+- The ELF class byte `e_ident[EI_CLASS]` (1=rv32, 2=rv64) is the truth for an
+  ELF's width. The repo's ELF reader already reads it (`elf_syms.cpp`).
+- **Two separate toolchains** (not one multilib):
+  `HYBRID_TOOLCHAIN` = rv64 (`nds64le`, `riscv64-unknown-elf-`),
+  `HYBRID_TOOLCHAIN32` = rv32 (`nds32le`, `riscv32-unknown-elf-`).
+- rv32 baseline = `-march=rv32gc -mabi=ilp32d` (the d23 engine has m,a,f,d,c),
+  mirroring rv64's `rv64gc/lp64d`.
+- **Runtime layout (decided):** rv64 stays at `build/runtime/` (back-compat with
+  the documented `-B build/runtime` link command); rv32 lands at
+  `build/runtime/rv32/`. Linked with `-B build/runtime/rv32`.
+

+#!/usr/bin/env bash
+# Build the user-facing andesim runtime (runtime/) for both arches. Produces:
+#   build/runtime/       libandesim_runtime.a, crt0.o, andesim.ld, andesim.specs,
+#                        include/andesim/ROI.h   (rv64; link -B build/runtime)
+#   build/runtime/rv32/  the same, rv32          (rv32; link -B build/runtime/rv32)
+# Users link with `-B <dir> -specs=andesim.specs` (USER_GUIDE.md section 5).
+#
+# rv64 always builds (HYBRID_TOOLCHAIN). rv32 builds too when HYBRID_TOOLCHAIN32
+# is set. Self-contained: fills either toolchain from config.env (exported env
+# wins), like setup.sh, so it runs without `source ./setup.sh` first.
+set -euo pipefail
+
+ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
+SRC="$ROOT/runtime"
+CONFIG_FILE="$ROOT/config.env"
+CONFIG_TEMPLATE="$ROOT/config.env.example"
+
+[[ -f "$SRC/Makefile" ]] || { echo "missing $SRC/Makefile" >&2; exit 1; }
+
+# Capture exported values (they win), then source config.env to fill any gaps.
+ENV_TC64="${HYBRID_TOOLCHAIN:-}"
+ENV_TC32="${HYBRID_TOOLCHAIN32:-}"
+if [[ -z "$ENV_TC64" || -z "$ENV_TC32" ]]; then
+  if [[ ! -f "$CONFIG_FILE" ]]; then
+    [[ -f "$CONFIG_TEMPLATE" ]] \
+      || { echo "missing $CONFIG_TEMPLATE; cannot create $CONFIG_FILE" >&2; exit 1; }
+    cp "$CONFIG_TEMPLATE" "$CONFIG_FILE"
+    echo "created $CONFIG_FILE from template -- edit it if your toolchains live elsewhere" >&2
+  fi
+  # shellcheck source=/dev/null
+  . "$CONFIG_FILE"
+fi
+[[ -n "$ENV_TC64" ]] && HYBRID_TOOLCHAIN="$ENV_TC64"
+[[ -n "$ENV_TC32" ]] && HYBRID_TOOLCHAIN32="$ENV_TC32"
+
+# rv64 (required).
+if [[ -z "${HYBRID_TOOLCHAIN:-}" || ! -d "${HYBRID_TOOLCHAIN:-}/bin" ]]; then
+  echo "HYBRID_TOOLCHAIN unset or has no bin/; check $CONFIG_FILE" >&2
+  exit 1
+fi
+make -C "$SRC" ARCH=rv64 TOOLCHAIN="$HYBRID_TOOLCHAIN"
+echo "built: $ROOT/build/runtime/libandesim_runtime.a (rv64)"
+
+# rv32 (optional: needs the second toolchain).
+if [[ -n "${HYBRID_TOOLCHAIN32:-}" && -d "${HYBRID_TOOLCHAIN32:-}/bin" ]]; then
+  make -C "$SRC" ARCH=rv32 TOOLCHAIN="$HYBRID_TOOLCHAIN32"
+  echo "built: $ROOT/build/runtime/rv32/libandesim_runtime.a (rv32)"
+else
+  echo "skipped rv32 runtime: set HYBRID_TOOLCHAIN32 in $CONFIG_FILE to build it" >&2
+fi
