    Remove icount trigger, simpoint-driven trigger, and cosim features
    
    Removes three feature families end to end (code, build, tests, docs):
    
    - icount trigger: the --mode icount / --hybrid-icount / plugin icount=
      instruction-count drain path.
    - simpoint-driven trigger: the BBV profile -> SimPoint cluster -> per-phase
      drain pipeline (hsim profile/cluster/estimate, --mode simpoint), the
      plugin bbv_out=/slice=/slice_at=/drain_at_exit= modes, bbv_emit, and the
      tools/simpoint submodule.
    - cosim: hybrid checkpoint co-sim (--cosim/--cosim-interval/--cosim-refine)
      and cycle lock-step DV (--mode cycle --cosim, --cosim-lockstep), the
      driver cosim_lockstep core, the plugin cosim_*/lockstep_* oracle modes,
      and cosim_redesign.md / the cosim tutorial notebook.
    
    Also removes the gem5-style warmup window (--vsim-warmup-icount, the
    mcycle/minstret_at_measure_start wire-ABI fields, and the orchestrator
    warmup/measure/total breakdown), which was specific to these paths.
    
    Survives: --mode fast|cycle|hybrid, the marker/pc triggers, --verify, the
    hybrid handoff, state drain/resume, and archive/replay. Bumps the verilator
    submodule to the matching hybrid-layer removal.
    
    Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>
