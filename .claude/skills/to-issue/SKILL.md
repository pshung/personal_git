# to-issue

## Overview
Document how to write an appropriate gitea issue/ticket using tea tool

## When to Use
when creating a gitea issue/ticket.

## Instructions
* Always write in ASD-STE100 Simplified Technical English.
* Issue tile must contain one of TAGS.
Feature: When building a new feature with implementation and tests.
Fix: Fixing an issue.
Docs: Only update documents.
Bug: Report a bug.
Test: Only 

## Output Format
The issue must follow the template for each TAG.
Feature: ./template-feature.md
Fix: ./template-fix.md
Docs: ./template-docs.md
Bug: ./template-bug.md
Test: ./template-test.md
